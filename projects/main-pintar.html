Main Pintar

Kuis edukatif bertema kearsipan untuk Dinas Kearsipan dan Perpustakaan (Diarpus) Kabupaten Kutai Kartanegara - mode solo dengan bonus kecepatan, dan live multiplayer dengan kode ruangan.

Proprieter - Diarpus Kukar PHP 8+ MySQL / MariaDB PWA v2.0.0
Buka Situs Live Repositori Release v2.0.0

Tangkapan Layar

Ringkasan

Aplikasi kuis edukatif dengan dua mode permainan: Mode Solo (sepuluh soal acak per kategori, timer per soal dengan bonus kecepatan) dan Mode Live Multiplayer (host membuat sesi dengan kode ruangan enam karakter; peserta bergabung dan soal tersinkron melalui polling tiap 3-4 detik, aman untuk limit hit shared hosting).

Fitur Utama

  • Tiga role pengguna - admin (dasbor, kelola soal/kategori/pengguna, analitik), peserta (kuis, leaderboard, statistik), dan guest (main tanpa akun, skor tidak masuk leaderboard).
  • Live multiplayer - monitor sesi real-time untuk host, distribusi jawaban, penyimpanan skor batch.
  • Kategori dan soal aktif/nonaktif - arsipkan tanpa menghapus; otomatis disembunyikan dari semua mode.
  • Leaderboard dan statistik - global dan per peserta: akurasi, tren bulanan, performa per kategori.
  • Multi-bahasa (ID/EN) - prioritas: akun pengguna, cookie, lalu setelan admin.
  • Notifikasi broadcast, pengaturan sistem (registrasi on/off, mode pemeliharaan), dan mode tamu dengan transfer data ke akun.
  • PWA - manifest, service worker, splash screen, halaman offline.

Instalasi Singkat

git clone https://github.com/mahakammoonlightstudio-beep/main-pintar-new.git
mysql -u USER -p NAMA_DATABASE < database.sql
mysql -u USER -p NAMA_DATABASE < database-upgrade.sql
cp includes/config.local.example.php includes/config.local.php  # isi kredensial + APP_SECRET
php -S localhost:8000

Ganti password akun admin default segera setelah instalasi. Pengguna Laravel Herd dapat memakai ~/.config/herd/bin/php84/php.exe -S localhost:8000. Kredensial tidak pernah ikut ke repositori.
