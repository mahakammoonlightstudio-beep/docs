Mahakam Moonlight Studio

Situs resmi studio - tempat imajinasi mengalir. Karya studio, cerita di baliknya, dan FAQ. Bootstrap 5.3, scene 3D bulan + bintang, dwibahasa, PWA-ready.

Buka Situs Live Repositori Release v3.0.0

Tangkapan Layar

Ringkasan

Wajah publik studio: kartu karya untuk setiap proyek (dengan status tayang dan tautan live), linimasa perjalanan studio, dan FAQ. Versi 3 memakai Bootstrap 5.3 ditambah lapisan desain kustom dengan aksen khas studio - vendor di-host sendiri, tanpa CDN.

Fitur Utama

  • Karya Studio - portofolio proyek dengan status (Tayang, Aktif, Produksi) dan tautan live per proyek.
  • Scene 3D khas studio - bulan 3D murni canvas (tanpa Three.js) dengan terminator realistis, bintang berkelip paralaks, dan shooting star acak; bereaksi terhadap kursor dan scroll.
  • Dwibahasa Indonesia / Inggris - teks ditandai atribut data-id / data-en, ditukar tanpa reload.
  • Transisi tema yang halus - pergantian terang/gelap dengan gradasi latar teranimasi dan cross-fade berbasis View Transitions API (fallback mulus).
  • Interaksi UI yang hidup - scroll-reveal, tilt 3D pada kartu, ripple tombol, progress baca, back-to-top, dan penghormatan prefers-reduced-motion.
  • Cerita dan FAQ - profil studio dan pertanyaan yang sering diajukan, dengan konten terkini.
  • PWA - manifest dan service worker untuk pemasangan dan akses offline.

Development

git clone https://github.com/mahakammoonlightstudio-beep/mms.git
cd mms
# Situs statis - cukup buka index.html atau jalankan server:
python -m http.server 8000

Bootstrap 5.3 sudah di-bundle di assets/vendor/ - tidak ada CDN, tidak ada langkah build wajib. Berkas verifikasi Google Search Console (google*.html) dikecualikan dari repositori - tambahkan langsung di server bila perlu verifikasi ulang.
