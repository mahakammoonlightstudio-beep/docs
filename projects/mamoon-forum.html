Mamoon Forum

Forum diskusi komunitas ringan berbasis PHP murni dan MySQL - posting anonim atau akun, tanpa framework, tanpa build step, tanpa CDN eksternal.

CC BY 4.0 PHP 7.4+ MySQL / MariaDB Tanpa Framework v2.0.0
Buka Live Demo Repositori Release v2.0.0

Tangkapan Layar

Ringkasan

Forum bergaya komunitas diskusi dengan dukungan posting anonim maupun akun terdaftar. Setiap halaman berukuran puluhan kilobyte dan tetap cepat di shared hosting. Versi 2.0.0 adalah penulisan ulang besar dengan fokus pada ringan dan cepat, ditambah fitur sosial: voting, reputasi, profil, dan edit konten.

Fitur Utama

  • Posting anonim atau akun - forum berfungsi penuh tanpa login; akun untuk voting, avatar, dan moderasi.
  • Voting thread dan balasan - upvote/downvote dengan toggle dan switch; satu vote per pengguna dijaga unique key di level database.
  • Pengurutan Terbaru / Teratas - berdasarkan waktu aktif atau skor vote, dengan badge Hot otomatis di atas ambang batas.
  • Reputasi - akumulasi skor vote dari seluruh thread dan balasan pengguna, dihitung langsung dari data vote.
  • Profil dan edit profil - statistik aktivitas, avatar dikompres otomatis maksimal 256px, ganti password.
  • Edit thread dan balasan - pembuat dapat mengubah konten; perubahan ditandai "(diedit)". Moderator dapat mengedit semua.
  • Kompresi gambar otomatis - unggahan di-resize maksimal 1280px, disimpan sebagai WebP/JPEG, umumnya puluhan KB.
  • Kategori, pencarian, sticky dan locked thread, pagination 20 thread / 15 balasan per halaman.
  • Tema terang dan gelap mengikuti preferensi sistem; notifikasi toast.

Keamanan

  • Prepared statements untuk seluruh query; output di-escape dengan htmlspecialchars.
  • CSRF token per sesi di setiap form POST; validasi URL tujuan untuk mencegah open redirect.
  • Unggahan divalidasi dari isi berkas (bukan ekstensi), diproses ulang via GD, eksekusi PHP dinonaktifkan di folder uploads.
  • Rate limit per IP untuk thread, balasan, vote, login, pendaftaran, dan edit profil; honeypot anti-spam bot.
  • Password disimpan dengan password_hash() (bcrypt).

Instalasi Singkat

git clone https://github.com/mahakammoonlightstudio-beep/mamoon-forum.git
mysql -u USER -p NAMA_DATABASE < database/schema.sql
cp config.example.php config.php    # lalu isi kredensial database
# opsional data demo: mysql -u USER -p NAMA_DATABASE < database/seed-demo.sql
php -S localhost:8000

Untuk database versi lama, jalankan pula database/upgrade.sql, upgrade-votes.sql, dan upgrade-edit.sql - semuanya aman terhadap data yang sudah ada. Pengguna Laravel Herd dapat memakai ~/.config/herd/bin/php84/php.exe -S localhost:8000. Panduan lengkap: README - Instalasi.
