Mahakam Moonlight Studio

Situs resmi studio - tempat imajinasi mengalir. Karya studio, cerita di baliknya, dan FAQ. Tailwind CSS v4, sepenuhnya statis, dwibahasa, PWA-ready.

CC BY 4.0 Tailwind CSS v4 PWA Dwibahasa v2.0.0
Buka Situs Live Repositori Release v2.0.0

Tangkapan Layar

Ringkasan

Wajah publik studio: kartu karya untuk setiap proyek (dengan status tayang dan tautan live), linimasa perjalanan studio, dan FAQ. Satu berkas CSS hasil build Tailwind v4 yang sudah di-minify - tanpa framework JavaScript.

Fitur Utama

  • Karya Studio - portofolio proyek dengan status (Tayang, Aktif, Produksi) dan tautan live per proyek.
  • Dwibahasa Indonesia / Inggris - teks ditandai atribut data-id / data-en, ditukar tanpa reload.
  • Cerita dan FAQ - profil studio dan pertanyaan yang sering diajukan, dengan konten terkini.
  • PWA - manifest dan service worker untuk pemasangan dan akses offline.

Development

git clone https://github.com/mahakammoonlightstudio-beep/mms.git
cd mms
npm install
npm run watch:css   # development
npm run build       # produksi: minify CSS

Butuh Node.js 18+. Berkas verifikasi Google Search Console (google*.html) dikecualikan dari repositori - tambahkan langsung di server bila perlu verifikasi ulang.
