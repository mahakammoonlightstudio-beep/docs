Kuis Arsip

Sistem kuesioner dan evaluasi kearsipan untuk Dinas Kearsipan dan Perpustakaan (Diarpus) Kabupaten Kutai Kartanegara - pengerjaan individu atau ruangan terjadwal, penilaian otomatis, sertifikat dengan verifikasi publik.

Proprieter - Diarpus Kukar PHP 8+ MySQL / MariaDB PWA v1.0.0
Buka Situs Live Repositori Release v1.0.0

Ringkasan

Sistem kuesioner kearsipan (bukan kuis santai): peserta mengerjakan survei secara individu atau di ruangan terjadwal dengan verifikasi kuota dan jadwal buka/tutup. Hasil dinilai otomatis lengkap dengan pembahasan per soal, dan sertifikat terbit otomatis setelah lulus - dapat diverifikasi publik.

Fitur Utama

  • Kuesioner berkode ruangan dan individu - verifikasi kuota, jadwal, pemeriksaan duplikasi pengerjaan, dan seed deterministik untuk pengacakan soal/opsi per peserta.
  • Penilaian dan sertifikat - penilaian otomatis dengan pembahasan, verifikasi sertifikat publik, pencetakan hasil.
  • Papan peringkat dan pencapaian - leaderboard dengan medali dan lencana (Juara Kelas, Sempurna, Rajin, Lulus).
  • Proctoring ringan - pencatatan perpindahan tab dan blur jendela selama ujian berjalan.
  • Multi-bahasa (ID/EN), notifikasi broadcast, dan preferensi pengguna.
  • Panel administrasi lengkap - kelola pengguna/kuesioner/ruangan, impor-ekspor data, analitik soal, helpdesk tiket, umpan balik, dan jejak audit batch.
  • PWA sinematik - service worker offline aman untuk data sesi, splash screen, tema gelap/terang dengan circular reveal.

Instalasi Singkat

git clone https://github.com/mahakammoonlightstudio-beep/kuis-arsip.git
mysql -u USER -p NAMA_DATABASE < database.sql
mysql -u USER -p NAMA_DATABASE < database-upgrade.sql
mysql -u USER -p NAMA_DATABASE < database_indexes.sql
cp config/config.local.example.php config/config.local.php  # isi kredensial
php -S localhost:8000

Ganti password akun admin default segera setelah instalasi. Pengguna Laravel Herd dapat memakai ~/.config/herd/bin/php84/php.exe -S localhost:8000. Folder backups/ dilindungi .htaccess dan tidak pernah ikut ke repositori.
