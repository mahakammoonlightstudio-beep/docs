Suara SMK

Platform penilaian dan masukan anonim untuk OSIS, MPK, dan ekstrakurikuler di SMKN 1 Tenggarong - rating bintang, komentar tersensor, dan panel admin dengan ekspor CSV.

CC BY 4.0 PHP 7.2+ MySQL / MariaDB PWA v1.0.0
Buka Situs Live Repositori Release v1.0.0

Ringkasan

Aplikasi web penilaian organisasi siswa yang ringan - dibangun dengan PHP native dan MySQL tanpa framework. Siswa memberi rating dan komentar anonim, panitia memantau hasil melalui panel admin, dan seluruh sistem berjalan di shared hosting.

Fitur Utama

  • Penilaian anonim - rating bintang dan komentar untuk tiap organisasi, dengan sensor kata kasar otomatis (daftar kata dapat dikonfigurasi).
  • Mode anti-duplikat - satu suara per hari per perangkat; dapat diatur per cookie, per IP, atau keduanya melalui konstanta DUPLICATE_MODE.
  • Panel admin - kelola organisasi, lihat hasil, ekspor CSV, reset data; dilindungi password ADMIN_PASSWORD.
  • Keamanan - CSRF token, session hardening (httponly, samesite), prepared statements PDO, sensor sebagian IP pada dashboard.
  • PWA - dapat dipasang dan berfungsi offline melalui manifest dan service worker.

Instalasi Singkat

git clone https://github.com/mahakammoonlightstudio-beep/suarasmk.git
mysql -u USER -p NAMA_DATABASE < database.sql
mysql -u USER -p NAMA_DATABASE < upgrade-voter-id.sql   # migrasi anti-duplikat
# buat config.local.php berisi kredensial + ADMIN_PASSWORD
php -S localhost:8000

File config.local.php tidak ikut ke repositori - isi kredensial di sana. Ganti ADMIN_PASSWORD default segera setelah deploy. Pengguna Laravel Herd dapat memakai ~/.config/herd/bin/php84/php.exe -S localhost:8000.
