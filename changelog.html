Rangkuman rilis publik seluruh proyek. Detail lengkap setiap rilis ada di halaman Releases masing-masing repositori.

v2.0.023 September 2026

Empat proyek merilis v2.0.0: pembangunan ulang dengan fitur besar.

  • Mamoon Forum Rewrite ringan dan cepat: voting thread dan balasan dengan anti-duplikat di level database, reputasi, halaman dan edit profil, edit konten oleh pembuatnya, kompresi gambar otomatis. Release notes
  • Main Pintar Mode Live Multiplayer dengan kode ruangan enam karakter, tiga role pengguna, kategori/soal aktif-nonaktif, leaderboard dan statistik. Release notes
  • Portfolio Migrasi ke pipeline resmi Tailwind CSS v4 dengan design token via @theme, dwibahasa, PWA, dan pembaruan konten proyek. Release notes
  • Situs Studio Migrasi ke Tailwind CSS v4, dwibahasa, PWA, dan pembaruan konten Mamoon-Forum yang resmi tayang. Release notes
v1.0.023 September 2026

Rilis stabil pertama bagi tiga proyek.

  • Suara SMK Rilis stabil pertama: penilaian anonim, anti-duplikat per perangkat, panel admin dengan ekspor CSV, PWA. Release notes
  • Kuis Arsip Rilis stabil pertama: kuesioner ruangan dan individu, sertifikat dengan verifikasi publik, panel administrasi lengkap. Release notes
  • Alasandong Rilis publik pertama: mesin kombinatorial sekitar 389.000 variasi alasan dwibahasa, kartu gambar, blog 9 artikel, PWA. Release notes
