Alasandong

Generator alasan otomatis - gratis, tanpa login, 100% berjalan di browser. Mesin kombinatorial merakit sekitar 389.000 variasi alasan dalam Bahasa Indonesia dan Inggris.

CC BY 4.0 Vanilla JS PWA Dwibahasa Tanpa Backend v1.0.0
Buka Situs Live Repositori Release v1.0.0

Ringkasan

Static site tanpa framework dengan mesin kombinatorial yang merakit kalimat dari slot opener x event x intensifier x followup x closer - menghasilkan sekitar 389.000 variasi (bukan daftar statis). Teks situasi bebas dari pengguna dijahit secara natural ke dalam alasan.

Fitur Utama

  • 12 kategori alasan - dari mangkir kerja sampai nolak pinjam uang, dengan 3 nada: Absurd, Savage, Santai dan Jujur.
  • Dua mode hasil - teks siap kirim, atau kartu gambar gaya NGL (canvas) dengan ukuran ekspor feed, story, dan persegi.
  • Dwibahasa ID/EN penuh - seluruh UI, bank alasan, mesin, dan kamus gaul; via menu Pengaturan atau parameter ?lang=en.
  • Blog 9 artikel dengan schema Article, BreadcrumbList, dan FAQPage untuk rich result.
  • Favorit, riwayat, dan kamus gaul - 30 istilah dwibahasa dalam kartu flip interaktif; data di localStorage.
  • Kustomisasi - 8 preset font, tema terang/gelap neon, efek suara Web Audio, warna adaptif mengikuti waktu.
  • PWA - installable dan offline-ready; privasi penuh karena tanpa backend.
  • SEO teknis - hreflang, canonical, JSON-LD, sitemap valid 15 URL, CLS 0.

Menjalankan Secara Lokal

git clone https://github.com/mahakammoonlightstudio-beep/alasandong.my.id.git
cd alasandong.my.id
python -m http.server 8000     # atau: npx serve .

100% statis tanpa build step. Bisa juga dibuka langsung lewat file://, tetapi Service Worker dan sebagian fitur hanya aktif pada http/https.
