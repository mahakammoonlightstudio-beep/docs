Tangkapan Layar

Ringkasan

Single page dengan bagian proyek terpilih, keahlian, perjalanan, dan ajakan kolaborasi. Versi 3 memakai Bootstrap 5.3 sebagai fondasi komponen ditambah lapisan desain kustom - tanpa framework JavaScript tambahan, tanpa CDN eksternal (semua vendor di-host sendiri).

Fitur Utama

  • Dwibahasa Indonesia / Inggris - teks ditandai atribut data-id / data-en dan ditukar tanpa reload.
  • Hero 3D interaktif - canvas 3D murni (tanpa Three.js): lapisan geometri parallax bergerak mengikuti kursor dan gyro perangkat, dengan penghormatan prefers-reduced-motion.
  • Transisi tema yang halus - pergantian terang/gelap menganimasikan gradasi latar langsung (keyframe morph) plus cross-fade berbasis View Transitions API dengan fallback mulus.
  • Interaksi UI yang hidup - scroll-reveal ber-IntersectionObserver, tilt 3D pada kartu, ripple pada tombol, lightbox galeri proyek, progress baca, back-to-top, salin email sekali klik, dan mode kontras tinggi.
  • PWA - manifest, service worker, dan ikon hasil generator otomatis (pure Node, tanpa dependensi).
  • Build pipeline Tailwind v4 - mode watch untuk development, minify untuk produksi; hasil build ikut di-commit sehingga situs langsung bisa dibuka.
  • Statis dan cepat - dapat di-hosting di GitHub Pages, Netlify, Vercel, atau shared hosting mana pun.

Development

git clone https://github.com/mahakammoonlightstudio-beep/cv-web-saya.git
cd cv-web-saya
# Situs statis - cukup buka index.html atau jalankan server:
python -m http.server 8000
# Build ikon PWA (opsional, murni Node tanpa dependensi):
npm run build:icons

Bootstrap 5.3 sudah di-bundle di assets/vendor/ - tidak ada CDN, tidak ada langkah build wajib.
